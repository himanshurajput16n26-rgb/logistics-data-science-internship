## Reference Dataset

DataCo SMART SUPPLY CHAIN FOR BIG DATA ANALYSIS

Official public source:
https://data.mendeley.com/datasets/8gx2fvg2k6/5

Download the dataset and place the CSV locally at:

`data/raw/DataCoSupplyChainDataset.csv`

The raw dataset is intentionally not included in this GitHub repository.

Do not upload confidential, personal, or proprietary logistics data to a public repository.
